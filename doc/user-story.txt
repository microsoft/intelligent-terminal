Demo Scenario
From Managing Agents to Managing Work
Demo Goal
This demo is not about:

Better agents
More agents
Multi-agent orchestration
Agent workforce management
This demo proves a more fundamental shift:

Today:
Users manage agents.

Tomorrow:
Users manage work.
Or:

Today:
Work belongs to Agents.

Tomorrow:
Agents belong to Work.
Story Setup
The entire demo revolves around a single Work:

Fix Issue #4821
This is intentional.

We don't want the audience thinking about:

Agents
Sessions
Tabs
Models
We want them thinking about:

One Work
because that is how humans naturally organize work.
